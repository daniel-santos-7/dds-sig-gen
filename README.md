# DDS Signal Generator

A VHDL Direct Digital Synthesis (DDS) signal generator that produces sine waves using a phase accumulator, lookup table, and amplitude scaler.

## Architecture

```
sig_gen (top-level)
├── pha_acc     — Phase accumulator (adds phase increment each clock)
├── sine_lut    — Lookup table for quarter-wave sine + waveform shaping
└── amp_scale   — Amplitude multiplier
```

The phase accumulator increments by a configurable value each clock cycle. The upper bits of the phase select entries from the sine lookup table, which stores only a quarter-wave (0°–90°). The `sine_lut` module mirrors and inverts this quarter-wave to reconstruct the full sine period. Finally, `amp_scale` multiplies the output by a configurable amplitude value.

## Building & Running

Requires [GHDL](https://ghdl.github.io/ghdl/).

```bash
make run
```

This compiles all RTL and testbench VHDL files, then runs the simulation. Waveforms are written to `waves/sig_gen_tb.ghw`.

### Override Simulation Parameters

| Variable | Default | Description |
|----------|---------|-------------|
| `CLK_FREQUENCY` | 50e6 | Input clock frequency in Hz |
| `OUT_FREQUENCY` | 1e6 | Desired output signal frequency in Hz |

```bash
make run CLK_FREQUENCY=100e6 OUT_FREQUENCY=2e6
```

### Clean

```bash
make clean
```

## Sine Lookup Table

The sine LUT in `rtl/sine_lut_pkg.vhd` is generated by a Python script, not at build time.

To regenerate:

```bash
cd py && make
```

Or directly:

```bash
python3 py/gen_sine_lut_pkg.py <addr_bits> <out_bits> <init_phase> <final_phase> > rtl/sine_lut_pkg.vhd
```

| Parameter | Default | Description |
|-----------|---------|-------------|
| `addr_bits` | 10 | LUT address width (2^10 = 1024 entries) |
| `out_bits` | 12 | Output resolution in bits |
| `init_phase` | 0 | Initial phase in degrees |
| `final_phase` | 90 | Final phase in degrees |

## Testbench

The testbench (`tbs/sig_gen_tb.vhd`) verifies:

1. **Phase correctness** — quarter-wave outputs positive, three-quarter-wave outputs negative
2. **Frequency accuracy** — measures zero-crossing period and compares to expected
3. **Amplitude scaling** — half-scale amplitude reduces peak by ~50%
